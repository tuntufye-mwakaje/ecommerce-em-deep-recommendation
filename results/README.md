# Results

This directory contains visual outputs generated during the
exploratory analysis and EM/GMM clustering experiments.

## Figures

The current results include visualizations for:

- Customer spending distribution
- Customer purchase frequency distribution
- Purchase frequency versus total spending
- Customer behavioral-feature correlation
- AIC/BIC model selection
- Cluster distribution
- Cluster profiles
- Customer clusters visualized using PCA

The figures document the exploratory and clustering stages of the
project.

No deep-recommendation evaluation results are currently included in
the public repository.
